# 边缘胶囊便签

适用于 `2.1.0-beta.7` 开发候选。胶囊让便签暂时收在屏幕边缘，需要时预览或继续编辑。

## 收起与展开

1. 按住便签顶部空白区域或“雾笺”品牌区域拖动。
2. 将便签移到屏幕工作区的左、右、上或下边缘附近，松开鼠标后收为胶囊。触发距离约为 16 个逻辑像素；普通窗口缩放不会触发收纳。
3. 在胶囊上悬停约 180 毫秒，打开只读预览；移开约 300 毫秒后恢复小胶囊。
4. 点击胶囊、预览正文或“点击展开编辑”，恢复完整便签。预览中的 `Esc` 也可以收起预览。

胶囊通常为 180×48，预览为 320×238，极小工作区会限制其尺寸以保持在屏幕内。正文预览最多显示 2,400 个字符，超出的内容仍保存在完整便签中。预览不会调用 AI 或修改正文。

原编辑器在收起期间保留在隐藏窗口中，因此展开后可以继续输入，并使用当前编辑会话原有的撤销与重做。退出应用后重开会恢复已保存内容与胶囊布局；撤销历史并不跨应用重启保存。

胶囊采用磨砂柔边、双细轮廓及静态角部刻线，跟随当前便签主题。背景仍是整体缓慢渐变，没有局部光斑。

## 多张便签与多屏

- 同一边缘的胶囊会寻找邻近空位，减少互相遮挡；边缘已放满时仍可能部分重叠。
- 胶囊按所属显示器和沿边比例保存位置。显示器移除或工作区改变时，会重新安排到可用工作区内。
- 从托盘菜单或任意便签“更多”面板中点击便签名称，也可以恢复完整窗口。

## 关闭自动收纳

打开“更多 → 本机设置”，关闭“拖到边缘自动收为胶囊”。现有胶囊会展开，之后拖到边缘也不会自动收起；重新勾选即可恢复功能。

## 本机布局与备份

便签正文、字号和主题继续使用原有版本 2 的便签数据。胶囊开关和位置另存于应用数据目录中的 `capsules.v1.json`，上一有效布局保存在 `capsules.previous.v1.json`。

“导出全部便签与配色”只导出便签及配色，不包含这两份机器相关的胶囊布局文件。将便签导入另一台电脑后，可按新屏幕重新收纳；原来的窗口尺寸仍按便签备份恢复并约束到可用工作区。

胶囊只是独立的透明小窗口，完整便签仍保持 260×260 的最小尺寸。布局文件写入失败或胶囊渲染异常时，恢复路径优先让完整便签可访问；布局文件损坏时保留原件，并停用胶囊布局以打开完整便签。

## 验证范围

新增自动测试覆盖四边检测、有限拖出、负坐标显示器、小工作区约束、同边避让、独立布局持久化及损坏文件保护。本轮自动测试共 68 项通过。

该功能仍随测试客户端交付。Windows、Intel Mac，以及实际多屏拔插和不同缩放比例下的交互仍需相应设备验收；几何测试不能代替这些实机检查。其他产品边界见 [已知问题](KNOWN_ISSUES.md)。
